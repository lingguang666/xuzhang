# 使用、备份与升级

## 日常使用

Start-Xuzhang.cmd 启动服务并打开浏览器。重复双击会回到同一个服务。默认从 4319 起寻找空闲端口，避免干扰已有服务。Stop-Xuzhang.cmd 停止本软件后台服务，Open-Data.cmd 打开数据目录。

初始化导入创建独立项目。先组织全篇问题与核心主张，再在章节蓝图维护分论点。把素材存到项目里，搜索具体内容后登记证据。主张用证据编号关联；作者核查来源、反例与边界。

## 完整备份

1. 等待网页显示已保存，停止所有续章 MCP 连接，再运行 Stop-Xuzhang.cmd。
2. 通过 Open-Data.cmd 打开数据目录，将**整个 data 文件夹**复制到备份位置。保留数据库、项目子文件夹及素材原件。
3. 恢复时先关闭连接及服务，另存当前 data 文件夹，然后将备份放回原位置。跨电脑迁移路径目前未提供向导，不要直接把库换到另一台电脑后假定素材路径已恢复。

网页中的“备份数据库”保留 SQLite 快照，不包含全部素材文件；导出记录 JSON 也不包含附件。

## 升级

先完整备份，关闭网页、MCP 连接与旧服务。把新版解压到新目录再启动。默认数据目录相同，旧文件会继续保留。软件移动后，Codex 配置里的可执行文件和脚本路径也需更新。首次测试版没有自动升级器。

## 故障

- 页面未打开：查看启动窗口提示，以及数据目录的 service.log。不要删除数据库。
- 首次启动后无法再次启动：先确认所有旧服务已停止；若只剩崩溃遗留的 launch.lock，可删除这个锁文件后重试。此文件不包含项目内容。
- 修改未保存：保留页面，先导出本地恢复记录，再修复连接。不要清空浏览器缓存。
- 文件无可检索文字：检查格式和提取状态；扫描 PDF 需要先做 OCR。
- 程序尚未做 Windows 代码签名，组织设备策略可能限制启动；请按组织软件使用规定处理。

## 确认资料位置与打开文件

新建 / 初始化导入时，先核对“当前创作项目文件夹”，勾选保存位置确认，再创建。可粘贴本机已有文件夹的完整路径；系统在其下建立“续章资料 / 独立项目编号”，各作品分别保存。网页无法获知 Codex 工作目录，显示的建议路径必须核对。已有项目继续使用原位置。

“素材与文件”中可以打开资料库文件夹；每个文件可“打开原文件”“在文件夹中显示”或下载。Windows 用默认程序打开常见文档、图片、音视频；其他类型请在文件夹中查看后自行打开。外部程序修改原文件后，旧文字定位会提示来源变化，应将新版作为新素材导入以保留历史。

资料文件夹保存原始素材和初始化导出；讨论、批注、蓝图及版本历史仍保存在续章 SQLite 数据库中。完整备份需要同时保留数据库备份和各项目资料目录，单独复制素材目录不能恢复全部工作记录。

## 从项目文件夹打开工作站

初始化完成后，所确认的项目文件夹会自动生成“打开续章工作站-作品名-项目编号.cmd”。Windows 中双击即可启动续章并直接进入该作品；已经运行时复用同一数据库的服务，不需要每次手动启动或记住端口。多个作品的入口分别命名。

入口引用当前安装的续章程序与数据库，不是独立运行包。请保留程序所在文件夹；移动程序位置后需要重新生成入口。入口缺失可沿原创建请求重试补齐，已有且被手动修改的入口不会覆盖。旧项目没有指定外层工作文件夹时，入口可放在其既有资料目录中。

## 更新与修改阶段

顶部“更新并查看改动”会载入最新已保存内容，并比较本页更新前的版本与最新版本，列出正文、思路、蓝图、决定、证据、批注等变化。若本页已经是最新版本，则显示最近一次保存的变化。有未保存输入、批注编辑或打开的编辑窗口时，会提示先处理，避免覆盖。

“修改阶段”按每次保存列出时间线，支持查看更早版本。选择阶段后可看当时的正文文字、思路与蓝图，以及相对上一版本的修改明细。第一版为线性版本时间线，不提供分支树或任意版本整体回滚。查看历史不写入或替换最新稿；需要恢复一组讨论成果时仍使用“讨论成果”的冲突检查恢复流程。

当前作品预览不再把所有曾被AI编辑的段落永久染红。比较视图中的红色只表示本次比较新增或改写的片段；删除内容见前后对照。“隐藏修改标记”仅改变显示，不删除历史。原稿和用户主动设置的颜色仍保留，可在作品预览选中文字后改色。长段落改写超过精细比较范围时会提示按范围标记。历史正文第一版按文字预览，图像、公式和表格版式仍在作品预览核对；素材原文件不属于该版本快照。
